# 1.2.4 — Server management, scheduled restarts and performance graphs

## TL;DR

- Manage each server from one window: settings, players, bans, messages and performance.
- Schedule restarts and optionally update Valheim automatically, with warnings before players get disconnected.
- See the last hour of performance—even if the window was closed. Keep the manager running to collect readings.
- Existing servers get the management tools automatically while stopped, unless you previously disabled them. Your worlds and settings stay in place; players don't need any mods.

This release adds a Server Management window for each world, automatic installation of management tools, scheduled restarts, player messaging and moderation, and clearer feedback during updates.

## Upgrading existing servers

- Servers without a previous management preference automatically receive BepInEx and the manager’s RCON companion while stopped. After an app update, installation happens before those servers restart.
- Running servers are left alone during this initial setup. They receive the tools once stopped or before their next launch.
- A previous explicit choice to disable management tools is preserved. Change it in **Server Management → Performance & Tools** while the server is stopped.
- Existing worlds, profiles, ports, access lists and startup preferences are retained. A failed installation does not mark setup complete, so it can be retried.
- Players do not need to install client mods for these management features. The tools do not change gameplay rules. The RCON connection is restricted to this Mac and uses a private per-server credential.

## A simpler menu and a dedicated management window

Each server’s submenu contains its join code, Start/Stop and **Server Management…**. The window brings together:

- **Performance & Tools:** game version, uptime, management-tool controls and performance graphs.
- **Automation:** start at login and scheduled restarts for that server.
- **Players & Moderation:** connected players, saved bans, and selection-based Kick, Ban and Unban controls with confirmation. Ban changes survive restarts.
- **Messages:** send a message to everyone on that server. Players see it in chat from **Server** and as a center-screen notification.

Settings, logs and recoverable server deletion are available from the same window. Running-server settings remain view-only. Status refreshes automatically; the manual Refresh Status button has been removed.

## One-hour performance graphs

- **Server Gameplay Loop Update Frequency** and **Managed memory** are sampled once per second.
- Readings continue while management windows are closed, as long as the manager is running. Reopening a window restores the last hour for that server.
- Clear lines replace the dots. Numbered gridlines and local timestamps make the charts easier to read.
- Missing readings and server restarts appear as gaps. Earlier readings remain visible after a server restart.
- History is held in memory and clears when the manager exits. Managed memory excludes native allocations. Gameplay loop frequency measures the server simulation, not client graphics FPS.
- Player ping is not displayed because crossplay does not expose a reliable measurement through this interface.

## Scheduled restarts

Set a restart time in local time, with daily, every-N-days or selected-weekday schedules. Choose to warn players and restart, wait until empty, or skip when occupied.

Player warnings appear at **15, 10, 5 and 1 minute**. The manager saves the world before stopping and restarting it. Stopped servers stay stopped. The maintenance log records the scheduled reason and the join code reported after startup. Missed schedules and manager relaunches are handled without repeating the same occurrence.

## Automatic official Valheim server updates

- Checks for a newer stable Valheim server build run every **10 minutes** while the manager is open.
- **Automatically Update All Valheim Servers** has an immediate checkmark and clearer explanatory text. It is off by default and preserves your existing choice on upgrade.
- This setting applies to the shared official server installation, so it affects all hosted worlds.
- Managed servers receive the 15/10/5/1-minute warning countdown, then save, stop, update and restart if they were running. Servers without working management tools wait until confirmed empty; unknown player counts block automatic updates.
- The menu bar now follows **Stopping → Updating → Starting**, with download progress when available.
- New bundled management components are installed automatically for servers with management enabled, using the maintenance workflow when a restart is needed. This does not install arbitrary community mods.

## Installation and verification

Download and unzip **Valheim-Server-Manager-for-Mac.zip**, then open the app and accept its replacement/update prompt. The download supports Apple Silicon and Intel Macs on macOS 13 or later and is Developer ID signed and Apple-notarized.

Validation includes automated regression tests, AppKit UI checks and isolated native-server lifecycle tests. See [verification details and coverage limits](../VERIFICATION.md). The general community mod catalog is not included in this release.
