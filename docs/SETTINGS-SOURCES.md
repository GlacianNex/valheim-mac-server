# Setting descriptions

Command tokens and available options are based on Iron Gate's dedicated-server guide and the launcher shipped with Valve app 896660:

- https://www.valheimgame.com/support/a-guide-to-dedicated-servers/

Numeric modifier descriptions are informational UI help inherited from the prototype and should be rechecked when game balance changes. Reference descriptions consulted during prototype development:

- https://www.nitroserv.com/en/guides/change-the-world-modifiers-of-your-valheim-server
- https://lagless.gg/docs/games/valheim/world-modifiers

Raid intervals are approximate eligibility checks, not guaranteed raid schedules. The native integration tests verify lifecycle and save behavior, not each in-game combat/drop modifier. The server remains the authority on supported flags and their effects.
